- **Zenarmor L7 Firewall Security:** Application-layer traffic inspection, web categorization, and security analytics deployed at the perimeter. *(Dedicated repo coming soon)*

- **Q-Feeds Threat Intelligence:** Integration of customized threat feed intelligence lists to tighten perimeter block policies. *(Dedicated repo coming soon)*

*Comprehensive infrastructure health monitoring, centralized log aggregation, and host-based intrusion detection.*

- **Zabbix Infrastructure Monitoring:** Proactive telemetry, resource tracking, and hardware health monitoring running on a Dell Inspiron 15 5566 in VLAN 110. *(Dedicated repo coming soon)*

### Program: Core Services & Infrastructure Management
*Self-hosted credential management, high-performance reverse-proxying, virtualization, and storage nodes.*
- **Secure Management Workstation:** Dedicated administration node running SysLinuxOS on a Microsoft Surface Pro 3 in VLAN 100, handling Ansible automation, network observability, and Level 1 backups. *(Dedicated repo coming soon)*
- **Proxmox VE Virtualization Cluster:** Enterprise hypervisor node hosted on a Dell Precision 7530 in VLAN 80, managing LXC/VM workloads and Docker containers. *(Dedicated repo coming soon)*
- **OpenMediaVault Storage Node:** Dedicated NAS backup and data persistence platform running on a Dell Inspiron 15 5568 in VLAN 130. *(Dedicated repo coming soon)*
- **Nginx Reverse Proxy & Vaultwarden:** Secure, TLS-terminated web serving and self-hosted encrypted credentials management. *(Dedicated repo coming soon)*
